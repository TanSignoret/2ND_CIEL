Séance 4 — Sécurité et gestion des mots de passe

TP — Découverte et utilisation de Bitwarden

Dans ce TP, vous allez découvrir Bitwarden, un gestionnaire de mots de passe open-source, pour comprendre l'importance des mots de passe forts, de la saisie automatique et de la centralisation de vos identifiants.

Seconde Bac Pro CIEL Durée : 2h Travail individuel
01

Contexte professionnel

Introduction

Dans une entreprise, la sécurité des mots de passe est une priorité absolue. Les employés doivent :

  • Utiliser des mots de passe forts et uniques pour chaque compte.
  • Éviter de réutiliser les mêmes mots de passe sur plusieurs services.
  • Stocker leurs mots de passe de manière sécurisée (ex: gestionnaire de mots de passe).
  • Activer la saisie automatique pour gagner du temps et éviter les erreurs.

Aujourd’hui, vous allez utiliser Bitwarden, un gestionnaire de mots de passe open-source, sécurisé et respectueux de la vie privée, pour :

  • Découvrir l’intérêt d’un gestionnaire de mots de passe.
  • Enregistrer vos mots de passe existants (ENT, Proton Mail).
  • Changer le mot de passe de votre boîte mail Proton et l’enregistrer dans Bitwarden.
  • Utiliser la saisie automatique pour vous connecter.
  • Installer l’extension Bitwarden dans votre navigateur.
02

TP 1 — Découverte de Bitwarden

3 étapes

Dans cette première partie, vous allez :

  • Créer un compte Bitwarden.
  • Installer l’extension Bitwarden dans votre navigateur.
  • Découvrir l’interface de Bitwarden.
  1. 1
    Créer un compte Bitwarden

    Rendez-vous sur Bitwarden et créez un compte gratuit :

    1. Cliquez sur "Créer un compte gratuit".
    2. Remplissez le formulaire :
      • Adresse email : Utilisez votre adresse Proton Mail (prenom.nom@proton.me).
      • Nom d'utilisateur : Choisissez un nom d'utilisateur (ex: prenom.nom).
      • Mot de passe maître : Créez un mot de passe très robuste (min. 16 caractères, majuscules, chiffres, symboles).
    3. Validez votre adresse email via le lien envoyé par Bitwarden.
    4. Connectez-vous à votre compte.
    Question 1

    Pourquoi le mot de passe maître doit-il être très robuste ?

  2. 2
    Installer l'extension Bitwarden

    Installez l’extension Bitwarden dans votre navigateur pour activer la saisie automatique :

    1. Selon votre navigateur :
      • Firefox : Lien vers l'extension.
      • Chrome/Edge : Lien vers l'extension.
    2. Cliquez sur "Ajouter à [Navigateur]".
    3. Connectez-vous à l’extension avec votre compte Bitwarden.
    Question 2

    Pourquoi installer l’extension Bitwarden dans son navigateur ?

    Validation

    L’extension Bitwarden est installée et connectée à votre compte.

  3. 3
    Découvrir l'interface de Bitwarden

    Explorez l’interface de Bitwarden (web ou extension) et repérez les éléments suivants :

    • Coffre-fort : Où sont stockés vos mots de passe.
    • Générateur de mots de passe : Pour créer des mots de passe forts.
    • Paramètres : Pour configurer votre compte.
    • Extensions et applications : Pour installer Bitwarden sur d’autres appareils.
    Question 3

    A quoi sert Bitwarden ?

TP 2 — Enregistrer des mots de passe existants

3 étapes

Dans cette partie, vous allez enregistrer vos mots de passe existants (ENT, Proton Mail) dans Bitwarden.

  1. 1
    Enregistrer le mot de passe de l'ENT

    Enregistrez votre mot de passe de l’ENT dans Bitwarden :

    1. Dans Bitwarden, cliquez sur "Ajouter un élément".
    2. Remplissez les champs :
      • Type : Connexion.
      • Nom : ENT - Lycée Charlie Chaplin.
      • Nom d'utilisateur : Votre identifiant ENT.
      • Mot de passe : Votre mot de passe ENT.
      • URL : https://charlie-chaplin.ent.auvergnerhonealpes.fr.
    3. Cliquez sur "Enregistrer".
    Question 3

    Comment avez-vous fait pour enregistrer le mot de passe de l’ENT dans Bitwarden ?

    Validation

    Le mot de passe de l’ENT est enregistré dans Bitwarden.

  2. 2
    Enregistrer le mot de passe de Proton Mail

    Enregistrez votre mot de passe de Proton Mail dans Bitwarden :

    1. Dans Bitwarden, cliquez sur "Ajouter un élément".
    2. Remplissez les champs :
      • Type : Connexion.
      • Nom : Proton Mail.
      • Nom d'utilisateur : Votre adresse Proton Mail (prenom.nom@proton.me).
      • Mot de passe : Votre mot de passe Proton Mail.
      • URL : https://mail.proton.me.
    3. Cliquez sur "Enregistrer".
    Validation

    Le mot de passe de Proton Mail est enregistré dans Bitwarden.

  3. 3
    Tester la saisie automatique

    Testez la saisie automatique avec Bitwarden :

    1. Ouvrez une nouvelle fenêtre de navigateur et accédez à Proton Mail.
    2. Cliquez sur le champ "Email".
    3. Bitwarden devrait vous proposer de remplir automatiquement votre email et mot de passe.
    4. Sélectionnez votre compte Proton Mail dans la liste.
    5. Validez la connexion.
    Question 4

    Quel est l’intérêt de la saisie automatique avec Bitwarden ?

    Validation

    La saisie automatique fonctionne pour Proton Mail.

04

TP 3 — Changer le mot de passe de Proton Mail et l'enregistrer dans Bitwarden

4 étapes

Dans cette partie, vous allez :

  • Changer le mot de passe de votre boîte mail Proton.
  • Mettre à jour le mot de passe dans Bitwarden.
  • Tester la nouvelle connexion.
  1. 1
    Changer le mot de passe de Proton Mail

    Changez le mot de passe de votre compte Proton Mail :

    1. Connectez-vous à Proton Mail.
    2. Cliquez sur l’icône ⚙️ Paramètres → "Compte" → "Mot de passe".
    3. Cliquez sur "Changer le mot de passe".
    4. Remplissez les champs :
      • Mot de passe actuel : Votre ancien mot de passe.
      • Nouveau mot de passe : Créez un mot de passe très robuste (min. 16 caractères, majuscules, chiffres, symboles).
      • Confirmer le nouveau mot de passe : Répétez le nouveau mot de passe.
    5. Cliquez sur "Enregistrer".
    Question 5

    Pourquoi est-il important de changer régulièrement son mot de passe ?

  2. 2
    Mettre à jour le mot de passe dans Bitwarden

    Mettez à jour le mot de passe de Proton Mail dans Bitwarden :

    1. Dans Bitwarden, trouvez l’élément "Proton Mail" que vous avez enregistré précédemment.
    2. Cliquez sur "Modifier".
    3. Mettez à jour le champ "Mot de passe" avec votre nouveau mot de passe.
    4. Cliquez sur "Enregistrer".
    Question 6

    Comment avez-vous fait pour mettre à jour le mot de passe de Proton Mail dans Bitwarden ?

    Validation

    Le mot de passe de Proton Mail est mis à jour dans Bitwarden.

  3. 3
    Tester la nouvelle connexion

    Testez la nouvelle connexion avec Bitwarden :

    1. Ouvrez une nouvelle fenêtre de navigateur en mode privé (pour éviter les caches).
    2. Accédez à Proton Mail.
    3. Cliquez sur le champ "Email".
    4. Bitwarden devrait vous proposer de remplir automatiquement vos identifiants.
    5. Sélectionnez votre compte Proton Mail et validez.
    6. Vérifiez que vous êtes bien connecté avec le nouveau mot de passe.
    Validation

    Vous êtes connecté à Proton Mail avec le nouveau mot de passe via Bitwarden.

  4. 4
    Ajouter un site ou une application mobile

    Ajoutez un nouveau mot de passe pour un site ou une application mobile :

    1. Choisissez un site ou une application que vous utilisez (ex: un réseau social, un jeu, etc.).
    2. Dans Bitwarden, cliquez sur "Ajouter un élément".
    3. Remplissez les champs :
      • Type : Connexion.
      • Nom : Le nom du site ou de l’application (ex: Twitter).
      • Nom d'utilisateur : Votre identifiant pour ce site.
      • Mot de passe : Votre mot de passe pour ce site.
      • URL : L’URL du site (ex: https://twitter.com).
    4. Cliquez sur "Enregistrer".
    Question 7

    Quel est l’intérêt d’ajouter un site ou une application dans Bitwarden ?

    Validation

    Un nouveau site ou une nouvelle application est enregistré dans Bitwarden.
