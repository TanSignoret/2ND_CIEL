Question 1

Pourquoi le mot de passe maître doit-il être très robuste ?

Réponse attendue : Le mot de passe maître est la clé principale qui protège tous vos autres mots de passe dans Bitwarden. Si quelqu’un découvre ce mot de passe, il aura accès à tous vos comptes. Il doit donc être impossible à deviner (ex: T3mP@ssW0rd!2026#CIEL).

Question 2

Pourquoi installer l’extension Bitwarden dans son navigateur ?

Réponse attendue : L’extension permet de :

  • Remplir automatiquement les champs de connexion (email, mot de passe).
  • Générer des mots de passe forts directement dans le navigateur.
  • Accéder rapidement à vos mots de passe enregistrés.

À quoi sert Bitwarden ?

Bitwarden est un gestionnaire de mots de passe qui permet de :

  • Stocker tous vos mots de passe en un seul endroit sécurisé.
  • Générer des mots de passe forts automatiquement.
  • Remplir automatiquement les champs de connexion.
  • Partager des mots de passe de manière sécurisée (ex: avec un collègue).
  • Synchroniser vos mots de passe entre tous vos appareils.

Question 3

Comment avez-vous fait pour enregistrer le mot de passe de l’ENT dans Bitwarden ?

Réponse attendue : J’ai cliqué sur "Ajouter un élément", puis j’ai rempli les champs (nom, nom d'utilisateur, mot de passe, URL) et j’ai enregistré.

Question 4

Quel est l’intérêt de la saisie automatique avec Bitwarden ?

Réponse attendue : La saisie automatique permet de :

  • Gagner du temps : Pas besoin de taper manuellement son email et mot de passe.
  • Éviter les erreurs : Pas de risque de se tromper en tapant son mot de passe.
  • Sécuriser ses connexions : Bitwarden remplit les champs de manière sécurisée.

Question 5

Pourquoi est-il important de changer régulièrement son mot de passe ?

Réponse attendue : Changer régulièrement son mot de passe permet de :

  • Limiter les risques en cas de fuite de données.
  • Respecter les bonnes pratiques de sécurité (ex: RGPD, politiques d’entreprise).
  • Renforcer la sécurité de son compte (un mot de passe ancien peut être compromis).

Question 6

Comment avez-vous fait pour mettre à jour le mot de passe de Proton Mail dans Bitwarden ?

Réponse attendue : J’ai trouvé l’élément "Proton Mail" dans Bitwarden, j’ai cliqué sur "Modifier", j’ai mis à jour le champ "Mot de passe" avec le nouveau mot de passe, puis j’ai enregistré.

Question 7

Quel est l’intérêt d’ajouter un site ou une application dans Bitwarden ?

Réponse attendue : Ajouter un site ou une application dans Bitwarden permet de :

  • Centraliser tous ses mots de passe en un seul endroit sécurisé.
  • Accéder rapidement à ses identifiants depuis n’importe quel appareil.
  • Utiliser la saisie automatique pour se connecter plus vite.
  • Générer des mots de passe forts pour chaque site.
