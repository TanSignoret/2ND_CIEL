TP — Utiliser un ordinateur dans le contexte profesionnel

Dans ce TP, vous allez maîtriser l'interface graphique (dossiers, fichiers, archives) et apprendre à utiliser un ordinateur uniquement avec le clavier, comme le feraient des professionnels dans un environnement sans souris.

01

Contexte professionnel

Introduction

Dans une entreprise, les employés doivent souvent :

  • Gérer des fichiers et dossiers : Créer, organiser, compresser et sécuriser des documents.
  • Travailler sans souris : Utiliser des raccourcis clavier pour naviguer, créer des fichiers ou envoyer des emails (ex: sur des serveurs sans interface graphique).
  • Respecter les autorisations : Comprendre les droits d’accès aux fichiers (lecture, écriture, exécution).
  • Optimiser leur productivité : Utiliser des outils comme les métadonnées ou les archives pour gagner du temps.

Aujourd’hui, vous allez :

  • Maîtriser l’interface graphique (dossiers, fichiers, archives).
  • Découvrir les métadonnées et les autorisations des fichiers.
  • Utiliser un ordinateur uniquement avec le clavier (recherche sur Internet, création de fichiers, envoi d’emails, etc.).
  • Participer à un concours de frappe pour améliorer votre vitesse de saisie.
02

TP 1 — Maîtriser l'interface graphique

6 étapes

Dans cette première partie, vous allez apprendre à :

  • Créer et organiser des dossiers et fichiers.
  • Comprendre les types de fichiers et leurs extensions.
  • Découvrir les autorisations (lecture, écriture, exécution).
  • Explorer les métadonnées des fichiers.
  • Compresser et décompresser des archives.
  1. 1
    Créer une arborescence de dossiers

    Créez la structure de dossiers suivante sur votre bureau ou dans votre dossier personnel :

    TP_Interface/
├── Documents/
│   ├── Cours/
│   │   ├── CIEL/
│   │   └── CultureG/
│   └── TP/
│       ├── TP1_Interface/
│       └── TP2_Clavier/
├── Images/
│   ├── Logos/
│   └── Captures/
└── Archives/
    1. Ouvrez l’Explorateur de fichiers (Win + E sur Windows, Alt + F2 → nautilus sur Linux).
    2. Sur votre bureau, créez un dossier nommé TP_Interface.
    3. À l’intérieur, créez les sous-dossiers selon l’arborescence ci-dessus.
    Pourquoi une arborescence ?

    Une arborescence bien organisée permet de :

    • Retrouver rapidement ses fichiers.
    • Éviter les doublons (ex: plusieurs versions d’un même fichier).
    • Faciliter la collaboration (les autres savent où trouver les documents).

    Validation

    Votre arborescence correspond au modèle ci-dessus.

  2. 2
    Créer des fichiers de différents types

    Créez les fichiers suivants dans les dossiers appropriés :

    Type de fichier Nom du fichier Emplacement Contenu
    Texte (.txt) notes.txt TP_Interface/Documents/Cours/CIEL/ Ajoutez le texte : Ceci est un fichier texte pour le TP Interface.
    PDF (.pdf) cours_CIEL.pdf TP_Interface/Documents/Cours/CIEL/ Exportez un document texte en PDF (ex: depuis LibreOffice).
    Image (.png) logo_lycee.png TP_Interface/Images/Logos/ Téléchargez le logo du lycée depuis son site web.
    Archive (.zip) archive_documents.zip TP_Interface/Archives/ Compressez le dossier Documents (voir étape 5).
    Validation

    Les fichiers sont créés dans les bons dossiers avec le bon contenu.

  3. 3
    Découvrir les types de fichiers et leurs extensions

    Les fichiers ont des extensions qui indiquent leur type. Voici une liste des extensions courantes :

    Catégorie Extensions Logiciel associé Description
    Texte .txt Bloc-notes, Notepad++ Fichier texte brut (sans mise en forme).
    .docx, .odt Word, LibreOffice Writer Fichier texte avec mise en forme.
    .pdf Adobe Acrobat, navigateur Fichier portable (non modifiable).
    Image .jpg, .jpeg Photoshop, GIMP, Aperçu Image compressée (perte de qualité).
    .png Photoshop, GIMP, Aperçu Image non compressée (qualité préservée).
    .gif Photoshop, navigateur Image animée.
    Archive .zip 7-Zip, WinRAR, Explorateur Windows Archive compressée (universelle).
    .rar, .7z WinRAR, 7-Zip Archive compressée (meilleur taux de compression).
    Exécutable .exe (Windows), .app (Mac) Système d'exploitation Programme exécutable.
    À retenir

    L’extension d’un fichier détermine :

    • Le type de fichier (texte, image, archive, etc.).
    • Le logiciel à utiliser pour l’ouvrir.
    • Les autorisations (ex: un fichier .exe peut être exécuté, contrairement à un .txt).

    Validation

    Vous avez compris les extensions des fichiers créés.

  4. 4
    Découvrir les autorisations des fichiers

    Les fichiers et dossiers ont des autorisations qui déterminent ce que les utilisateurs peuvent faire. Voici les principales autorisations :

    Autorisation Symbole (Linux) Description Exemple
    Lecture (Read) r Permet de lire le fichier ou de lister le contenu d’un dossier. Un fichier texte que vous pouvez ouvrir.
    Écriture (Write) w Permet de modifier le fichier ou d’ajouter/supprimer des fichiers dans un dossier. Un document Word que vous pouvez éditer.
    Exécution (Execute) x Permet d’exécuter le fichier (pour les programmes) ou d’entrer dans un dossier. Un fichier .exe ou un script .sh.

    Exercice : Vérifiez les autorisations des fichiers que vous avez créés :

    1. Sur Windows :
      • Faites un clic droit sur notes.txt → Propriétés → Onglet Sécurité.
      • Observez les autorisations pour votre utilisateur.
    2. Sur Linux :
      • Ouvrez un terminal et tapez : ls -l TP_Interface/.
      • Observez les permissions (ex: -rw-r--r-- pour un fichier en lecture/écriture pour le propriétaire et lecture seule pour les autres).
    Exemple de permissions Linux

    La commande ls -l affiche des permissions comme drwxr-xr-x :

    • d : Dossier (au lieu de - pour un fichier).
    • rwx : Lecture (r), écriture (w), exécution (x) pour le propriétaire.
    • r-x : Lecture et exécution pour le groupe.
    • r-x : Lecture et exécution pour les autres.

    Validation

    Vous avez vérifié les autorisations de vos fichiers.

  5. 5
    Découvrir les métadonnées

    Les métadonnées sont des informations sur un fichier (auteur, date de création, taille, etc.). Elles sont utiles pour organiser et retrouver des fichiers.

    Exercice : Affichez les métadonnées du fichier notes.txt :

    1. Sur Windows :
      • Faites un clic droit sur notes.txt → Propriétés.
      • Observez les onglets Général (taille, date de création) et Détails (auteur, titre, etc.).
    2. Sur Linux :
      • Ouvrez un terminal et tapez : stat TP_Interface/Documents/Cours/CIEL/notes.txt.
      • Observez les informations affichées (taille, date de modification, etc.).
    À quoi servent les métadonnées ?

    Les métadonnées permettent de :

    • Trier et filtrer les fichiers (ex: par date de création).
    • Retrouver rapidement un fichier (ex: recherche par auteur).
    • Automatiser des tâches (ex: sauvegarder les fichiers modifiés aujourd’hui).

    Validation

    Vous avez affiché les métadonnées du fichier notes.txt.

  6. 6
    Compresser et décompresser des archives

    Les archives permettent de regrouper et compresser plusieurs fichiers/dossiers en un seul fichier.

    1. Compresser le dossier Documents :
      • Cliquez droit sur le dossier Documents (dans TP_Interface/).
      • Sélectionnez 7-Zip → Ajouter à l'archive....
      • Choisissez :
        • Format : ZIP.
        • Nom : archive_documents.zip.
        • Emplacement : TP_Interface/Archives/.
      • Cliquez sur OK.
    2. Décompresser l'archive :
      • Ouvrez le dossier TP_Interface/Archives/.
      • Cliquez droit sur archive_documents.zip.
      • Sélectionnez 7-Zip → Extraire ici.
      • Vérifiez que le dossier Documents est bien extrait.
    3. Protéger une archive par mot de passe (optionnel) :
      • Compressez le fichier notes.txt en ZIP avec un mot de passe (ex: BacPro2026).
      • Nommez l'archive notes_protegee.zip.
      • Testez : Demandez à un camarade d’essayer d’extraire l’archive (il ne devrait pas y arriver sans le mot de passe).
    Pourquoi compresser ?

    Compresser des fichiers permet de :

    • Réduire la taille (gain de place sur le disque ou en pièce jointe).
    • Regrouper plusieurs fichiers en un seul.
    • Protéger les fichiers avec un mot de passe.

    Validation

    Vous avez compressé et décompressé l’archive archive_documents.zip.
