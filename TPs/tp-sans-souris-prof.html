Correction — TP Utilisation d'un PC sans souris

Document synthétique avec les réponses attendues et les raccourcis clavier associés.

📌 Réponses aux questions et raccourcis clavier

Question 1 : Quelle solution est la plus simple pour verrouiller rapidement votre session Windows ?
Raccourci : Win + L
Réponse : Utiliser le raccourci clavier Win + L.
Question 2 : Quelle solution est la plus simple pour ouvrir un logiciel comme Bloc-notes sans souris ?
Raccourci : Win + taper le nom du logiciel + Entrée
Réponse : Utiliser le menu Démarrer avec Win, taper le nom du logiciel, puis valider avec Entrée.
Question 3 : Quelle solution est la plus simple pour enregistrer un fichier sans souris ?
Raccourci : Ctrl + S
Réponse : Utiliser le raccourci clavier Ctrl + S.
Question 4 : Quelle solution est la plus simple pour basculer entre plusieurs fenêtres ouvertes ?
Raccourci : Alt + Tab
Réponse : Utiliser le raccourci clavier Alt + Tab.
Question 5 : Quelle solution est la plus simple pour fermer une fenêtre sans souris ?
Raccourci : Alt + F4
Réponse : Utiliser le raccourci clavier Alt + F4.
Question 6 : Quelle solution est la plus simple pour créer un nouveau dossier sans souris ?
Raccourci : Ctrl + Maj + N
Réponse : Utiliser le raccourci clavier Ctrl + Maj + N.
Question 7 : Quelle solution est la plus simple pour copier un fichier sans souris ?
Raccourci : Ctrl + C
Réponse : Utiliser le raccourci clavier Ctrl + C.
Question 8 : Quelle solution est la plus simple pour enregistrer un fichier dans un dossier spécifique sans souris ?
Raccourci : Ctrl + Maj + S (pour "Enregistrer sous")
Réponse : Utiliser le raccourci clavier Ctrl + Maj + S pour ouvrir la fenêtre "Enregistrer sous", puis naviguer avec les flèches.
Question 9 : Quel nombre avez-vous trouvé pour "La réponse à la grande question de la vie" ?
Réponse : Le nombre est 42 (référence à "Le Guide du voyageur galactique").
Question 10 : Quelle est la valeur binaire de 42 sur 8 bits ?
Réponse : La valeur binaire est 00101010.
Question 11 : Quelle solution est la plus simple pour fermer un onglet ou une fenêtre de navigateur sans souris ?
Raccourci : Ctrl + W (pour fermer un onglet) ou Alt + F4 (pour fermer la fenêtre)
Réponse : Utiliser le raccourci clavier Ctrl + W pour fermer un onglet.
Question 12 : Quelle solution est la plus simple pour faire une capture d'écran sans souris ?
Raccourci : Win + Maj + S
Réponse : Utiliser le raccourci clavier Win + Maj + S pour sélectionner une zone, ou Impr. écran pour capturer tout l'écran.
Question 13 : Quelle solution est la plus simple pour coller une image dans Paint sans souris ?
Raccourci : Ctrl + V
Réponse : Utiliser le raccourci clavier Ctrl + V.
Question 14 : Quelle solution est la plus simple pour ouvrir le gestionnaire de tâches sans souris ?
Raccourci : Ctrl + Maj + Échap
Réponse : Utiliser le raccourci clavier Ctrl + Maj + Échap.
Question 15 : Quelle solution est la plus simple pour naviguer dans les onglets du gestionnaire de tâches sans souris ?
Raccourci : Tab et Entrée
Réponse : Utiliser Tab pour naviguer entre les onglets et Entrée pour sélectionner.
Question 16 : Quelle solution est la plus simple pour organiser deux fenêtres côte à côte sans souris ?
Raccourci : Win + ← (gauche) et Win + → (droite)
Réponse : Utiliser les raccourcis clavier Win + ← et Win + → pour ancrer les fenêtres à gauche et à droite.
