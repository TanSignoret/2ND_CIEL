TP — Interface graphique et utilisation sans souris

Dans ce TP, vous allez maîtriser l'interface graphique (dossiers, fichiers, archives) et apprendre à utiliser un ordinateur uniquement avec le clavier, comme le feraient des professionnels dans un environnement sans souris.

01

Contexte professionnel

Introduction

Dans une entreprise, les employés doivent souvent :

  • Gérer des fichiers et dossiers : Créer, organiser, compresser et sécuriser des documents.
  • Travailler sans souris : Utiliser des raccourcis clavier pour naviguer, créer des fichiers ou envoyer des emails (ex: sur des serveurs sans interface graphique).
  • Respecter les autorisations : Comprendre les droits d’accès aux fichiers (lecture, écriture, exécution).
  • Optimiser leur productivité : Utiliser des outils comme les métadonnées ou les archives pour gagner du temps.

Aujourd’hui, vous allez :

  • Maîtriser l’interface graphique (dossiers, fichiers, archives).
  • Découvrir les métadonnées et les autorisations des fichiers.
  • Utiliser un ordinateur uniquement avec le clavier (recherche sur Internet, création de fichiers, envoi d’emails, etc.).
  • Participer à un concours de frappe pour améliorer votre vitesse de saisie.

TP 2 — Utiliser un ordinateur sans souris

7 étapes

Dans cette partie, vous allez apprendre à utiliser votre ordinateur uniquement avec le clavier. Cela est utile pour :

  • Travailler sur des serveurs sans interface graphique.
  • Gagner en productivité (les raccourcis clavier sont plus rapides que la souris).
  • Accéder à un ordinateur en cas de panne de souris.

Consigne : Pour ce TP, ne pas utiliser la souris !

  1. 1
    Naviguer dans l'interface avec le clavier

    Apprenez à naviguer dans l’interface de votre ordinateur avec le clavier :

    Action Raccourci Windows Raccourci Linux
    Ouvrir le menu Démarrer / Lancer un programme Win Alt + F2
    Ouvrir l'Explorateur de fichiers Win + E Alt + F2 → tapez nautilus → Entrée
    Basculer entre les fenêtres ouvertes Alt + Tab Alt + Tab
    Fermer une fenêtre Alt + F4 Alt + F4
    Ouvrir le menu contextuel (clic droit) Maj + F10 Maj + F10
    Sélectionner un élément Flèches + Tab Flèches + Tab
    Valider / Ouvrir Entrée Entrée
    Annuler Échap Échap

    Exercice : Ouvrez l’Explorateur de fichiers et naviguez jusqu’au dossier TP_Interface en utilisant uniquement le clavier.

    Validation

    Vous avez ouvert l’Explorateur de fichiers et navigué jusqu’à TP_Interface sans souris.

  2. 2
    Rechercher sur Internet

    Ouvrez votre navigateur et effectuez une recherche sur Internet sans souris :

    1. Ouvrez votre navigateur :
      • Windows : Win → tapez Chrome ou Firefox → Entrée.
      • Linux : Alt + F2 → tapez firefox → Entrée.
    2. Naviguez jusqu’à la barre d’adresse :
      • Tab jusqu’à ce que la barre d’adresse soit sélectionnée.
    3. Tapez https://www.google.fr et validez avec Entrée.
    4. Effectuez une recherche :
      • Tab pour sélectionner la barre de recherche.
      • Tapez métadonnées fichier et validez avec Entrée.
    5. Naviguez dans les résultats :
      • Utilisez Tab pour sélectionner un résultat.
      • Entrée pour ouvrir le lien.
    Validation

    Vous avez effectué une recherche sur Internet sans souris.

  3. 3
    Créer un nouveau document texte et l'enregistrer

    Créez un nouveau document texte et enregistrez-le sans souris :

    1. Ouvrez un éditeur de texte :
      • Windows : Win → tapez Bloc-notes → Entrée.
      • Linux : Alt + F2 → tapez gedit → Entrée.
    2. Tapez le texte suivant : 
      Ce document a été créé sans utiliser la souris.
Je maîtrise maintenant les raccourcis clavier !
    3. Enregistrez le fichier :
      • Ctrl + S (ou Ctrl + Maj + S pour "Enregistrer sous").
      • Naviguez jusqu’au dossier TP_Interface/Documents/TP/TP2_Clavier/ avec les flèches.
      • Nommez le fichier document_sans_souris.txt.
      • Validez avec Entrée.
    Validation

    Le fichier document_sans_souris.txt est créé dans TP_Interface/Documents/TP/TP2_Clavier/.

  4. 4
    Envoyer un email

    Envoyez un email à votre professeur sans souris :

    1. Ouvrez Proton Mail :
      • Win → tapez Proton Mail → Entrée.
      • Connectez-vous avec Tab et Entrée.
    2. Créez un nouvel email :
      • N (raccourci pour "Nouveau message").
    3. Remplissez les champs :
      • Tab pour passer d’un champ à l’autre.
      • Destinataire : tanguy.signoret@ac-lyon.fr.
      • Objet : TP Sans Souris - [VOTRE_NOM].
      • Contenu : 
        Bonjour Monsieur,

Je vous envoie ce mail pour vous informer que j’ai terminé le TP sur l’utilisation du clavier.
Ce mail a été rédigé et envoyé sans utiliser la souris.

Cordialement,
[VOTRE_PRÉNOM] [VOTRE_NOM]
    4. Envoyez l’email :
      • Ctrl + Entrée.
    Validation

    Votre email est envoyé à votre professeur sans utiliser la souris.

  5. 5
    Fermer un onglet et en ouvrir un nouveau

    Fermez un onglet et ouvrez-en un nouveau sans souris :

    1. Ouvrez votre navigateur (si ce n’est pas déjà fait).
    2. Ouvrez un nouvel onglet :
      • Ctrl + T.
    3. Naviguez jusqu’à la barre d’adresse et tapez https://www.ratatype.com/.
    4. Fermer l’onglet actuel :
      • Ctrl + W.
    5. Rouvrez un nouvel onglet et accédez à Proton Mail.
    Raccourcis utiles pour les onglets

    Action Raccourci Windows/Linux
    Nouvel onglet Ctrl + T
    Fermer l'onglet Ctrl + W
    Onglet suivant Ctrl + Tab
    Onglet précédent Ctrl + Maj + Tab
    Rouvrir le dernier onglet fermé Ctrl + Maj + T

    Validation

    Vous avez fermé et rouvert des onglets sans souris.

  6. 6
    Taper rapidement au clavier (concours)

    Participez à un concours de frappe pour améliorer votre vitesse de saisie :

    1. Ouvrez votre navigateur et accédez à Ratatype (utilisez les raccourcis clavier pour naviguer).
    2. Cliquez sur "Typing Test" (utilisez Tab et Entrée).
    3. Choisissez un test de frappe (ex: 1 minute, 3 minutes ou 5 minutes).
    4. Tapez le texte qui s’affiche aussi vite et précisément que possible.
    5. À la fin du test, notez :
      • Votre vitesse de frappe (en mots par minute, WPM).
      • Votre précision (en %).
    Pourquoi améliorer sa vitesse de frappe ?

    Une bonne vitesse de frappe permet de :

    • Gagner du temps (rédaction de documents, emails, etc.).
    • Réduire la fatigue (moins de temps passé à taper).
    • Être plus productif dans un environnement professionnel.

    Validation

    Vous avez participé au concours de frappe et noté vos résultats.

  7. 7
    Concours en classe

    Organisez un concours de frappe en classe :

    1. Chaque élève effectue un test de 3 minutes sur Ratatype.
    2. Notez les résultats de chaque élève dans un tableau (ex: sur le tableau du cours).
    3. Déterminez :
      • L’élève avec la meilleure vitesse de frappe (WPM).
      • L’élève avec la meilleure précision (%).
      • L’élève avec le meilleur score global (vitesse + précision).
    Exemple de tableau de résultats

    Élève Vitesse (WPM) Précision (%) Score global
    Jean DUPONT 45 98% 44.1
    Marie MARTIN 50 95% 47.5

    Score global = Vitesse × (Précision / 100).

    Validation

    Le concours est organisé et les résultats sont notés.
