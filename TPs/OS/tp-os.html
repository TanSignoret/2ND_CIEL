Partie 1 — Préparer la clé bootable et l'environnement de travail

45 min
Situation professionnelle

Votre tuteur de stage vous demande de préparer une clé bootable afin d'installer un nouveau système d'exploitation suite à la récéption d'un oridnateur.

Étape 1 — Installer le poste de travail

  1. 1
    Aller chercher le matériel

    À l'entrée de la salle, prendre : un PC de test, un écran et un clavier.

  2. 2
    Brancher et vérifier

    S'installer à une paillasse, puis brancher : écran → prise vidéo, clavier → USB, alimentation. Avant d'allumer : vérifier chaque branchement.

    Allumer et noter ce que vous observez comme OS :

    • Marque : ____________
    • Mdoèle : ____________
    • Marque : ____________
    • Numéro de licence : ____________

Étape 2 — Télécharger l'ISO

  1. 1
    Téléchargement officiel

    Aller chercher une distribution Linux. L'enregistrer dans un dossier facile à retrouver. Vérifier l'extension .iso et la taille du fichier : un téléchargement interrompu donne un ISO corrompu qui fera échouer le boot.

Étape 3 — Créer la clé USB bootable avec Rufus

  1. 1
    Lancer Rufus

    Brancher la clé fournie (elle sera effacée — vérifier avec le professeur qu'elle ne contient rien). Dans Rufus : Périphérique = votre clé.

  2. 2
    Choisir l'ISO

    Sélection de démarrage → Sélectionner → pointer l'ISO Ubuntu téléchargée. Schéma de partition : GPT (UEFI) ou MBR selon l'âge de la machine de test.

  3. 3
    Graver et vérifier

    Démarrer → confirmer l'effacement → patienter (5-10 min). En fin de processus, la clé contient le bootloader + fichiers d'installation : elle est bootable. Faire une capture d'écran de la fenêtre Rufus configurée pour le compte rendu.

Question 4

Que vient « écrire » Rufus sur la clé pour la rendre bootable ?

Étape 4 — Démarrer sur la clé (5 min)

🧭 Procédure à adapter : faites preuve d'initiative

La méthode « entrer dans le Setup avec Suppr/F2 et modifier l'ordre de boot » est une méthode, mais elle n'est pas toujours la bonne : selon la machine, on passera par le menu de boot ponctuel (F12, F9, Échap…), par les réglages UEFI de Windows, ou il faudra d'abord désactiver le Secure Boot.

  1. 1
    Brancher la clé et allumer la machine de test

    Brancher la clé, allumer, et accéder au menu de boot ou au Setup. Touche(s) utilisée(s) : ____________

  2. 2
    Démarrer sur la clé USB

    Choisir la clé USB comme support de démarrage. La machine démarre sur la clé → écran d'accueil Ubuntu.

Partie 2 — Deux missions

Situation professionnelle

Votre tuteur de stage vous demande de procéder en 2 étapes :

  • Mission 1 : Vérfier les informations présentent sur le disque de la machine.
  • Mission 2 : Installer un système d'exploitation sur la machine : soit en dualboot, soit avec uniquement un nouvel OS.

🛰️ Mission 1 — Explorer le PC depuis la clé, en mode live

Étape 1 — Démarrer sans installer

Sur l'écran d'accueil Ubuntu, choisissez « Essayer Ubuntu » (et non « Installer ») : l'OS se charge entièrement en RAM, sans rien écrire sur le disque. Vous voilà sur un bureau Linux complet, sur une machine dont le système d'origine est intact.

Étape 3 — Les risques : les données à portée de main

Depuis le système live, vous pouvez parcourir les fichiers du disque sans connaître le mot de passe de la session Windows. C'est exactement ce que ferait une personne malveillante avec une clé bootable.

🎯 Mission 2 — Installer un OS (au choix du binôme) (≈ 60 min)

🤔 À vous de choisir

Option A — Installation complète : Ubuntu remplace tout ce qui est sur le disque. Plus simple, plus rapide, mais Windows est effacé.
Option B — Dual boot : Ubuntu est installé à côté de Windows, et un menu propose le choix du système à chaque démarrage. Plus technique, mais le système existant est conservé.

Notez dans votre compte rendu votre choix.

Étape 1 — Protéger l'existant

Indispensable pour le remplacement d'un OS, bonne pratique dans tous les cas : on relève la licence Windows avant de toucher au disque.

  1. 1
    Relever la clé

    Démarrer la machine sur Windows. Ouvrir l'invite de commandes (Win+R → cmd) et saisir :
    wmic path softwarelicensingservice get OA3xOriginalProductKey
    Sinon : chercher l'étiquette COA collée sur le boîtier. (Si vous avez choisi l'option A et que Windows ne démarre plus, passez directement à l'étape 2.)

  2. 2
    Noter et conserver

    Recopier la clé (25 caractères) dans le compte rendu : ____________________
    Un professionnel documente toujours son intervention : la clé notée, c'est une réinstallation Windows possible plus tard.

Question 10

Pourquoi relever la licence Windows avant de modifier le disque, alors que le dual boot est censé préserver Windows ?

Étape 2 — Installer

  1. 1
    Redémarrer sur la clé

    Redémarrer la machine sur la clé (même méthode qu'en partie 1).

  2. 2
    Option A — Effacer et installer

    Choisir « Installer Ubuntu », puis « Effacer le disque et installer Ubuntu » (OK uniquement sur machine de test !) : le disque est formaté et partitionné automatiquement.

  3. 3
    Option B — Installer à côté de Windows

    Choisir « Installer Ubuntu », puis « Installer Ubuntu à côté de [Windows] » : le disque est redimensionné pour faire de la place. Ne jamais choisir « Effacer le disque » : Windows serait supprimé !

    ⚠️ Avant de valider le partitionnement : faire valider par le professeur. Le redimensionnement de partition est une opération délicate.

  4. 4
    Finaliser

    Compte utilisateur, mot de passe, puis patienter pendant l'installation. Retirer la clé au redémarrage.

    Notez impérativement les informations des utilisateurs créé !
