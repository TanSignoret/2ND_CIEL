Introduction

Prérequis

Dans cette séquence, vous allez apprendre à utiliser deux outils essentiels pour votre parcours en Bac Pro CIEL :

  • Proton Mail : pour créer une adresse email professionnelle et sécurisée.
  • Proton Drive : pour organiser et partager tes documents dans le cloud.

Ces outils sont utilisés en entreprise pour leur sécurité et leur respect de la vie privée.

Matériel nécessaire

Pour suivre ce TP, vous aurez besoin de :

  • Un poste informatique avec accès à Internet.
  • Un navigateur web (Firefox, Chrome, Edge).
  • Tes identifiants ENT (fournis par le lycée).
  • Un traitement de texte (LibreOffice Writer ou Word).

Exo 1 - Faire un Contre Rendu de TP

Livrables

Tout au long des TPs, vous allez devoir remplir un document de contre rendu.

À chaque étape vous aurez une ou deux questions à répondre, pensez à bien le remplir au fur et à mesure.

  1. 1
    Créer un dossier et un document
    • Allez dans le dossier Document de l'ordinateur.
    • Créer un dossier :
      • Comment faire Click droit -> Nouveau -> Dossier
      • Nom du dossier : TP_CIEL_2026
    • Allez dans le dossier TP_CIEL_2026.
    • Créer un document texte : Click droit -> Nouveau -> Document texte.
      • Nom du document : monpremierdocument.odt
    Validation

    Ton document apprait bien dans le dossier Document/TP_CIEL_2026.

  2. 2
    Remplir un document texte
    • Dans le document texte créé, note les informations suivante :
      • Ton nom et prénom
      • Ta classe
      • Les questions du sujet : Copie (Ctrl + c) puis Colle (Ctrl + V) la question
    • Enregistre ce document :
      • Via le logiciel : Fichier -> Enregistrer
      • Raccourcis clavier : Ctrl + S
    Validation

    Ton document apprait bien dans le dossier Document.

  3. 3
    Renommer un document
    • Allez dans le dossier Document puis TP_CIEL_2026.
    • Vous devez voir apparaitre votre docuement texte.
    • Pour renomer un document, il existe plusieurs méthode :
      • Via le logiciel : Fichier -> Enregistrer sous
      • Raccourcis clavier : F12 ou Ctrl + F2
      • Via l'explorateur de fichier : Click droit -> Renommer
    • Respecter le format suivant : TP_[SUJET]_[maClasse]_[NOM]_[Prenom].[extension]
    Règles à respecter

    Nommage des fichiers :

    Tous les fichiers que vous créez doivent suivre cette convention :

    Exemple : TP_ENT_2CIEL_DUPONT_Jean.png

    ❌ Interdit : espaces, accents, caractères spéciaux (! @ # $ % ^ & *).

    ✅ Les types de fichiers autorisés : .docx, .pdf, .png, .jpg

    Validation

    Ton document apprait bien dans le dossier Document/TP_CIEL_2026/ avec le nom qui respecter les règles.

Exo 2 — Créer une boîte mail professionnelle avec Proton Mail

5 étapes

Dans ce TP, vous allez créer une adresse email professionnelle avec Proton Mail, un service de messagerie chiffré et respectueux de la vie privée.

Proton Mail est utilisé par des millions de personnes et d'entreprises pour protéger leurs communications.

  1. 1
    Créer un compte Proton Mail
    • Rends-toi sur Proton Mail et crée un compte gratuit.

      • Clique sur "Créer un compte gratuit".
      • Choisis l'option Gratuite (500 Mo de stockage).
      • Remplis le formulaire :
        • Nom d'utilisateur : prenom.nom (ex: tanguy.signoret).
        • Adresse email : prenom.nom@proton.me.
        • Mot de passe : Robuste (min. 12 caractères, majuscules, chiffres, symboles).
      • Valide ton adresse email via le lien de confirmation envoyé par Proton (vérifie tes spams si nécessaire).
      • Connecte-toi à ton compte.
    Validation

    Votre compte est créé et vous êtes connecté.

  2. 2
    Découvrir l'interface de Proton Mail
    • Explore l'interface de Proton Mail :
      • Boîte de réception (Inbox)
      • Bouton "Nouveau message" (Compose)
      • Dossiers : Brouillons (Drafts), Envoyés (Sent), Corbeille (Trash)
      • Options de chiffrement (icône 🔒)

    Attendu :

    • Insère une capture d'écran de l'accueil de Proton Mail dans ton contre rendu.
    Aide

    Faire une capture d'écran :

    Appuyer sur la touche "Impr. écran" (ou "PrtScn") pour capturer l'écran entier.

    On ouvre un logiciel de traitement de texte (Word, Open office), on colle (Ctrl+V), on fait un clic droit sur l'image puis enregistrer.

  3. 3
    Envoyer un email professionnel

    Envoie un email à ton professeur (tanguy.signoret@ac-lyon.fr) avec les éléments suivants :

    • Destinataire : tanguy.signoret@ac-lyon.fr.
    • Objet : TP Mail - [TON_NOM] [TON_PRÉNOM] (ex: TP Mail - SIGNORET Tanguy).
    • Contenu :
    Bonjour Monsieur,

Je vous envoie ce mail dans le cadre du TP sur la communication en ligne.
Voici le lien vers le site du lycée : [le lien du site du lycée].

Respectueusement,
[TON_PRÉNOM] [TON_NOM]
    • Voir un exemple 
        Destinataire : tanguy.signoret@ac-lyon.fr
Objet : TP Mail - DUPONT Jean

Bonjour Monsieur,

Je vous envoie ce mail dans le cadre du TP sur la communication en ligne.
Voici le lien vers le site du lycée : https://charlie-chaplin.ent.auvergnerhonealpes.fr

Respectueusement,
Jean DUPONT
    À retenir

    Un email professionnel doit toujours contenir :

    • Un objet clair et court.
    • Une formule de politesse (Bonjour, Cordialement, etc.).
    • Une signature avec ton nom et prénom.
    Validation

    Ton email est envoyé et visible dans le dossier "Envoyés".

  4. 4
    Recevoir et répondre à un email

    Demande à un camarade de t'envoyer un email sur ton adresse Proton Mail avec un objet et un contenu simple.

    Réponds-lui en :

    • Cliquant sur "Répondre" (Reply).
    • Ajoutant une phrase de remerciement.
    • Signant avec ton nom et prénom.
    Validation

    Ta réponse est visible dans le dossier "Envoyés".

  5. 5
    Organiser sa boîte mail
    • Créer un dossier nommé Bac_Pro_CIEL et déplace-y l'email reçu de ton camarade.
      • Clique sur "Dossiers" (ou "Labels") dans la barre latérale.
      • Sélectionne "Créer un dossier".
      • Nomme-le Bac_Pro_CIEL et valide.
      • Glisse-dépose l'email dans ce dossier.

Exo 3 — Organiser la GED avec Proton Drive

6 étapes

Dans ce TP, vous allez utiliser Proton Drive, un espace de stockage cloud sécurisé lié à ton compte Proton Mail.

Tu vas y créer une arborescence (organisation de dossiers), déposer des fichiers, et les partager avec ton professeur.

  1. 1
    Accéder à Proton Drive

    Depuis ton compte Proton Mail, clique sur l'icône "Drive" dans la barre latérale (ou va sur drive.proton.me).

    Proton Drive est un espace de stockage chiffré : tes fichiers sont protégés même si le serveur de Proton est piraté.

    Pourquoi Proton Drive ?

    Contrairement à Google Drive, Proton Drive chiffre tes fichiers : même Proton ne peut pas y accéder sans ton mot de passe.

    Validation

    Tu es sur la page d'accueil de Proton Drive.

  2. 2
    Créer une arborescence

    Recréer exactement cette arborescence dans Proton Drive :

    Bac_Pro_CIEL/
├── Cours/
│   ├── ENT/
│   └── GED/
├── TP/
│   ├── TP1_ENT/
│   └── TP2_GED/
└── Ressources/

    Une arborescence, c'est la façon dont les dossiers et les fichiers sont organisés les uns dans les autres, comme les branches d'un arbre.

    • Quelques étapes pour t'aider à créer cette arborescence
      • Crée le dossier Bac_Pro_CIEL à la racine de Proton Drive.
      • À l'intérieur, crée les dossiers Cours, TP et Ressources.
      • Dans Cours, crée les sous-dossiers ENT et GED.
      • Dans TP, crée les sous-dossiers TP1_ENT et TP2_GED.
    • Créer un dossier
      • Clique sur "Nouveau dossier" (icône +).
      • Nomme le dossier.
      • Ouvre le dossier et répète l'opération pour les sous-dossiers.
    Comment créer des dossiers ?
    1. Clique sur "Nouveau dossier" (icône +).
    2. Nomme le dossier (ex: Bac_Pro_CIEL).
    3. Ouvre le dossier et répète l'opération pour les sous-dossiers.
    Validation

    Ton arborescence correspond au modèle ci-dessus.

  3. 3
    Déposer un fichier dans Proton Drive

    Télécharge la page des clubs du lycée en PDF :

    1. Va sur la page des clubs du lycée Charlie Chaplin.
    2. Fais un clic droit → "Imprimer" (ou Ctrl + P).
    3. Dans la fenêtre d'impression, sélectionne "Enregistrer au format PDF".
    4. Enregistre le PDF sur ton bureau avec le nom : clubs_lycee.pdf.

    Dépose ce PDF dans le dossier Bac_Pro_CIEL/TP/TP2_GED/ avec le nom :

    TP_GED_2CIEL_TON_NOM_TON_PRÉNOM.pdf
    Comment déposer un fichier ?
    1. Ouvre le dossier de destination dans Proton Drive.
    2. Glisse-dépose le fichier depuis ton explorateur de fichiers.
    3. Ou clique sur "Télécharger" et sélectionne le fichier.
    Validation

    Le fichier TP_GED_2CIEL_[TON_NOM]_[TON_PRÉNOM].pdf est dans TP2_GED.

  4. 4
    Partager un dossier avec ton professeur

    Partage le dossier TP2_GED avec ton professeur (tanguy.signoret@ac-lyon.fr) en lecture seule.

    Comment partager un dossier ?
    1. Clic droit sur le dossier TP2_GED.
    2. Sélectionne "Partager".
    3. Ajoute l'email : tanguy.signoret@ac-lyon.fr.
    4. Choisis les droits : "Peut voir" (lecture seule).
    5. Clique sur "Envoyer l'invitation".
    Validation

    Ton professeur confirme avoir accès au dossier TP2_GED.

  5. 5
    Rédiger une fiche de synthèse

    Dans le compte rendu créer en début de séance :

    • Télécharge la page des clubs du lycée en PDF
      • Va sur la page des clubs du lycée Charlie Chaplin.
      • Fais un clic droit → "Imprimer" (ou Ctrl + P).
      • Dans la fenêtre d'impression, sélectionne "Enregistrer au format PDF".
      • Enregistre le PDF sur ton bureau avec le nom : clubs_lycee.pdf.
    • Dépose ce PDF dans le dossier Bac_Pro_CIEL/TP/TP2_GED/ avec le nom :
      • TP_GED_2CIEL_TON_NOM_TON_PRÉNOM.pdf
    • Comment déposer un fichier
      • Ouvre le dossier de destination dans Proton Drive.
      • Glisse-dépose le fichier depuis ton explorateur de fichiers.
      • Ou clique sur "Télécharger" et sélectionne le fichier.
    Validation

    Le fichier TP_GED_2CIEL_[TON_NOM]_[TON_PRÉNOM].pdf est dans TP2_GED.

    Validation

    Le document TP_GED_Synthese_2CIEL_[TON_NOM]_[TON_PRÉNOM].docx est dans TP2_GED et partagé.

  6. 6
    Vérifier les livrables

    Assurez-vous qu'il y a bien :

    • Le PDF des clubs est dans TP2_GED avec le bon nom.
    • Le document de synthèse est dans TP2_GED et partagé.
    • Ton professeur a bien reçu l'invitation pour accéder à TP2_GED.
    Livrables 2 et 3

    • Le PDF des clubs, nommé correctement.
    • Le document de synthèse, partagé avec ton professeur.

Lexique

Vocabulaire
Mot Définition
Cloud Stockage de données sur des serveurs distants, accessibles via Internet.
Chiffrement de bout en bout Technologie qui protège les données (emails, fichiers) pour que seul le destinataire puisse les lire.
RGPD Règlement Général sur la Protection des Données : loi européenne pour protéger les données personnelles.
Proton Mail Service de messagerie chiffré, respectueux de la vie privée.
Proton Drive Espace de stockage cloud sécurisé lié à Proton Mail, avec chiffrement de bout en bout.
Arborescence Organisation des dossiers et fichiers les uns dans les autres.
Extension Les lettres après le point dans un nom de fichier (.png, .docx) : elles indiquent le type de fichier.
Livrable Le travail fini que vous devez remettre, dans la forme demandée.
