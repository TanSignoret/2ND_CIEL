Seconde Bac Pro CIEL 1 séance de 4h Travail individuel 25 défis · 250 points Compte rendu sur Pronote
🎯 Le principe

Ce TP est un CTF (Capture The Flag). Chaque défi cache un flag, une chaîne de la forme CIEL{...}.

À vous de le trouver en explorant la page : le HTML, le CSS, le JavaScript, les cookies, l'URL, le stockage et les échanges réseau.

Tous les défis sont sur cette page même : c'est elle que vous allez disséquer.

⚖️ Règles du jeu — à lire avant de commencer
  • Internet est autorisé : documentation, recherches, tutos. Un technicien sait chercher.
  • IA : NON.
  • Le « hacking » consiste à comprendre un système pour en trouver les failles.
    Sans autorisation, c'est un délit (article 323-1 du Code pénal : accès frauduleux à un système de traitement automatisé de données).
  • Ici, la cible est cette page de TP : l'autorisation est explicite. Ailleurs (école, commerce, camarade), jamais par défaut : sans accord écrit, c'est une attaque.
  • C'est le métier du pentester : chercher les failles avec autorisation pour qu'elles soient corrigées. En entreprise : mandat écrit, toujours.
