la balise oubliée = bug n°1

🧱🎨 Séparer les rôles

contenu dans .html,

📋 L'essentiel en une phrase

Le serveur envoie du texte, le navigateur le transforme en page : le HTML la structure en balises emboîtées (head + body, blocs header/section/article/table), le CSS l'habille, le JavaScript l'anime — et tout cet arbre s'appelle le DOM.
