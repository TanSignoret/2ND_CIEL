🎯 Attaques principales
  • Phishing → C (vol d'identifiants)
  • Rançongiciel → D (sauvegarde 3-2-1 = seule parade)
  • DDoS → D (saturation du serveur)
  • Man-in-the-middle → I + C (interception)
🧼 Hygiène numérique
  • Mot de passe : 12+ caractères, unique + gestionnaire (Bitwarden)
  • 2FA activée partout
  • Mises à jour régulières (OS, navigateur)
  • Antivirus à jour · Wi-Fi public → VPN
  • Signaler une fuite RGPD à la CNIL sous 72 h
🎣 Repérer un phishing

Expéditeur suspect · objet alarmiste · urgence artificielle · lien ≠ site officiel · pièce jointe inattendue. Une entreprise légitime ne demande jamais ton mot de passe par mail.

02

Carte mère

Circuit principal
🧩 À connaître
  • Processeur : le cerveau de l'ordinateur
  • Socket : support du CPU, un par génération (LGA1155, AM3) — système ZIF (Zero Insertion Force)
  • Chipset : coordonne les échanges (anciens : North Bridge = mémoire/CPU rapide, South Bridge = USB/disques lent)
  • Bus : lignes de données, d'adresses, de contrôle
⚙️ BIOS & démarrage
  • Stocké en EEPROM Flash (non volatile, flashable)
  • POST : diagnostic au démarrage
  • Setup (touche Suppr) : réglages gardés dans la RAM CMOS, alimentée par la pile
  • Chargeur d'amorce : cherche un secteur d'amorce → « No bootable device » = pas d'OS, pas une panne !
📐 Formule du débit

Débit (b/s) = vitesse (Hz) × largeur (bits) × transferts/cycle — 1 octet = 8 bits ; Mbps → Mo/s : diviser par 8.
Ex. DDR PC-1600 : 64 × 100×10⁶ × 2 = 1 600 octets/s.

03

Mémoires & stockage

Volatile ou non
Type Volatile ? En une phrase Usage
SRAM Oui Bascule, très rapide, chère, sans rafraîchissement Cache CPU
DRAM Oui Condensateur qui fuit → rafraîchie des milliers de fois/s, économique Barrettes RAM
ROM → Flash Non ROM → PROM (1 fois) → EPROM (UV) → EEPROM (électrique) → Flash (~100 000 écritures) BIOS, clés USB

⚡ Les 3 chiffres du SSD
  • SATA III : plafond ~550 Mo/s
  • NVMe (PCIe, M.2) : 3 000-7 000 Mo/s
  • M.2 = format, pas un bus (M.2 SATA ≠ M.2 NVMe)
