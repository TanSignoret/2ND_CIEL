Module — Productivité et efficacité

Utiliser un ordinateur de manière professionnelle

Maîtriser les raccourcis clavier et les bonnes pratiques pour travailler efficacement dans un environnement professionnel.

Seconde Bac Pro CIEL Durée : 1h Théorie et pratique
01

Contexte professionnel

Introduction

Dans un environnement professionnel, savoir utiliser un ordinateur efficacement est essentiel pour :

  • Gagner du temps : Les raccourcis clavier permettent d’effectuer des tâches plus rapidement que avec une souris.
  • Travailler sans souris : Dans certains contextes (ex: serveurs, environnements distants), la souris n’est pas disponible.
  • Être plus productif : Réduire les mouvements inutiles et automatiser les tâches répétitives.
  • Respecter les normes : Dans certaines entreprises, l’utilisation des raccourcis clavier est encouragée pour optimiser l’efficacité.

Ce cours vous présentera les raccourcis clavier essentiels pour :

  • Changer de fenêtre ou de bureau virtuel.
  • Ouvrir ou fermer des onglets dans un navigateur.
  • Ouvrir ou fermer un logiciel.
  • Éteindre ou mettre en veille une session.
  • Et bien plus encore !
02

Pourquoi utiliser des raccourcis clavier ?

Théorie

Les raccourcis clavier offrent de nombreux avantages dans un contexte professionnel :

Avantages des raccourcis clavier

  • Rapidité : Effectuer des actions en une fraction de seconde (ex: Ctrl + C pour copier).
  • Précision : Éviter les erreurs liées à l’utilisation de la souris (ex: clic sur le mauvais bouton).
  • Accessibilité : Permettre aux personnes en situation de handicap (ex: mobilité réduite) d’utiliser un ordinateur.
  • Productivité : Réduire la fatigue et le temps passé sur des tâches répétitives.
  • Polyvalence : Fonctionner dans tous les environnements (Windows, Linux, MacOS).

Exemple concret : Un employé qui utilise des raccourcis clavier peut :

  • Copier et coller du texte 2 fois plus vite qu’avec une souris.
  • Naviguer entre plusieurs fenêtres sans perdre de temps.
  • Effectuer des tâches complexes (ex: gestion de fichiers) sans quitter le clavier.

🖥️ Bureaux virtuels

Qu'est-ce qu'un bureau virtuel ?

Les bureaux virtuels permettent d’organiser vos fenêtres en plusieurs espaces de travail. Cela est utile pour :

  • Séparer les tâches (ex: un bureau pour le travail, un autre pour les loisirs).
  • Éviter l’encombrement de la barre des tâches.
  • Travailler plus efficacement en basculant entre les bureaux.

Action Raccourci Windows Raccourci Linux (GNOME) Description
Créer un nouveau bureau virtuel Win + Tab → + Super + Page Up Ajoute un nouveau bureau virtuel.
Changer de bureau virtuel Win + Ctrl + ← ou → Super + Page Up/Down Passer d’un bureau virtuel à un autre.
Déplacer une fenêtre vers un autre bureau Win + Maj + ← ou → Super + Maj + Page Up/Down Déplace la fenêtre active vers un autre bureau.
Fermer un bureau virtuel Win + Tab → × sur le bureau Super + Maj + Page Up (ferme le bureau actuel) Ferme le bureau virtuel actuel.

Bonnes pratiques pour une utilisation professionnelle

Conseils

Voici quelques bonnes pratiques pour utiliser un ordinateur de manière professionnelle :

1. Organiser son espace de travail

  • Utilisez des bureaux virtuels pour séparer les tâches (ex: un bureau pour le travail, un autre pour les loisirs).
  • Organisez vos fichiers et dossiers dans une arborescence claire.
  • Utilisez des raccourcis sur le bureau pour les logiciels les plus utilisés.

2. Maîtriser les raccourcis clavier

  • Apprenez les raccourcis de base (Ctrl + C, Ctrl + V, etc.).
  • Utilisez les raccourcis spécifiques à votre métier (ex: Ctrl + S pour enregistrer souvent).
  • Personnalisez les raccourcis si nécessaire (ex: dans des logiciels comme Photoshop ou Blender).

3. Optimiser sa productivité

  • Utilisez des outils de productivité comme :
    • Gestionnaires de tâches : Todoist, Trello, Microsoft To Do.
    • Gestionnaires de mots de passe : Bitwarden, KeePass.
    • Outils de collaboration : Slack, Microsoft Teams, Discord.
  • Automatisez les tâches répétitives avec des scripts (ex: PowerShell, Bash).
  • Utilisez des extensions de navigateur pour gagner du temps (ex: uBlock Origin, Dark Reader).

4. Sécuriser son poste de travail

  • Verrouillez votre session quand vous vous éloignez (Win + L ou Super + L).
  • Utilisez un mot de passe robuste (min. 12 caractères, majuscules, chiffres, symboles).
  • Activez la MFA (Multi-Factor Authentication) sur vos comptes (email, réseaux sociaux, etc.).
  • Mettez à jour régulièrement votre système d’exploitation et vos logiciels.

5. Respecter les règles de l'entreprise

  • Respectez la charte informatique de votre entreprise (ex: pas d’usage personnel des outils professionnels).
  • Ne stockez pas de données sensibles sur votre bureau ou dans des dossiers non sécurisés.
  • Utilisez les outils approuvés par votre entreprise (ex: Proton Mail au lieu de Gmail pour les emails sensibles).
  • Signalez toute anomalie (ex: email suspect, logiciel qui ne fonctionne pas).

05

Exercices pratiques

À faire en classe

Voici quelques exercices pratiques pour vous entraîner à utiliser les raccourcis clavier :

Exercice 1 : Naviguer entre les fenêtres

  1. Ouvrez 3 logiciels différents (ex: navigateur, traitement de texte, calculatrice).
  2. Utilisez Alt + Tab pour basculer entre les fenêtres.
  3. Fermez chaque fenêtre avec Alt + F4.

Exercice 2 : Gérer les onglets du navigateur

  1. Ouvrez votre navigateur et accédez à https://www.google.fr.
  2. Ouvrez 5 onglets avec Ctrl + T.
  3. Naviguez entre les onglets avec Ctrl + Tab et Ctrl + Maj + Tab.
  4. Fermez les onglets un par un avec Ctrl + W.
  5. Rouvrez le dernier onglet fermé avec Ctrl + Maj + T.

Exercice 3 : Utiliser les bureaux virtuels

  1. Créez 2 bureaux virtuels (Win + Tab → + sur Windows, Super + Page Up sur Linux).
  2. Ouvrez un navigateur sur le premier bureau et un traitement de texte sur le deuxième bureau.
  3. Basculez entre les bureaux avec Win + Ctrl + ←/→ (Windows) ou Super + Page Up/Down (Linux).
  4. Déplacez le navigateur vers le deuxième bureau avec Win + Maj + ←/→ (Windows) ou Super + Maj + Page Up/Down (Linux).

Exercice 4 : Gérer une session

  1. Verrouillez votre session avec Win + L (Windows) ou Super + L (Linux).
  2. Déverrouillez-la avec votre mot de passe.
  3. Mettez votre ordinateur en veille avec Win + D → Alt + F4 (Windows) ou Super + L → Mettre en veille (Linux).
  4. Réveillez votre ordinateur et vérifiez que tout est toujours ouvert.

Exercice 5 : Concours de raccourcis

  1. En classe, organisez un concours de rapidité :
  2. Chaque élève doit effectuer les actions suivantes le plus vite possible :
    1. Ouvrir le navigateur.
    2. Ouvrir 3 onglets.
    3. Basculer entre les onglets.
    4. Fermer les onglets.
    5. Ouvrir un traitement de texte.
    6. Taper un texte court (ex: "Je maîtrise les raccourcis clavier !").
    7. Enregistrer le fichier.
    8. Fermer le logiciel.
  3. Le premier à terminer gagne !
