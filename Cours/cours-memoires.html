Cours — Les mémoires d'un ordinateur

SRAM, DRAM et DDR

Comprendre les différents types de mémoire vive et reconnaître les grandes familles de barrettes utilisées dans un ordinateur.

02

SRAM et DRAM

Deux technologies

La mémoire vive n'utilise pas une seule technologie. Deux familles importantes sont la SRAM et la DRAM.

TypeCaractéristiqueUtilisation
SRAMTrès rapideMémoire cache du processeur
DRAMUtilisée comme mémoire principaleRAM de l'ordinateur
À retenir

SRAM → cache · DRAM → mémoire principale.

03

La SRAM : la mémoire cache

Très rapide

La SRAM (Static RAM) est une mémoire très rapide. Elle est notamment utilisée pour constituer la mémoire cache du processeur.

La mémoire cache permet au processeur d'accéder très rapidement à certaines informations dont il a besoin.

Repère

Quand tu vois SRAM dans ce cours, pense d'abord à cache du processeur.

04

La DRAM : la mémoire principale

RAM

La DRAM (Dynamic RAM) est utilisée comme mémoire principale de l'ordinateur.

Les barrettes de RAM que l'on installe dans un ordinateur appartiennent à cette famille.

Question

Un ordinateur possède une mémoire cache et des barrettes de RAM. Quelle technologie associer à chacune ?

Réponse : SRAM → cache ; DRAM → mémoire principale.

05

DDR : Double Data Rate

Mémoire vive

DDR signifie Double Data Rate.

Le principe est de réaliser deux transferts de données par cycle d'horloge.

DDR
 │
 └── Double Data Rate
       │
       └── 2 transferts de données par cycle d'horloge

Les générations ont évolué : DDR, DDR2, DDR3, DDR4, puis DDR5.

À retenir

DDR = deux transferts de données par cycle.

06

DDR3, DDR4 : attention à la compatibilité

Installation

Les différentes générations de DDR ne sont pas interchangeables.

Par exemple, une barrette DDR4 ne peut pas être installée sur une carte mère prévue pour la DDR3.

Pourquoi ?

La position de l'encoche sur la barrette et les caractéristiques électriques diffèrent selon les générations.

SituationCompatible ?
Barrette DDR3 + carte mère DDR3Oui, si les autres caractéristiques conviennent.
Barrette DDR4 + carte mère DDR3Non.
Barrette DDR3 + carte mère DDR4Non.
07

DIMM et SO-DIMM

Format

Il faut également reconnaître le format physique de la barrette.

  • DIMM : format courant dans les ordinateurs de bureau.
  • SO-DIMM : format compact, notamment utilisé dans les ordinateurs portables.
Repère

Portable → pense généralement SO-DIMM. Ordinateur de bureau → pense généralement DIMM.

08

Synthèse

À retenir
Mémoire
 │
 ├── SRAM → cache processeur
 │
 └── DRAM → mémoire principale
       │
       └── DDR → 2 transferts par cycle
             ├── DDR3
             ├── DDR4
             └── DDR5
Mini-mission

On te donne un ordinateur portable à mettre à niveau. Quel format de mémoire dois-tu rechercher en priorité ?

Réponse : SO-DIMM, puis vérifier la génération DDR compatible avec la carte mère.
