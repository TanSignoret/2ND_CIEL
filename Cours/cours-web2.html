Les essentiels du HTML

Comprendre les balises, structurer une page et connaître les éléments indispensables. Chaque notion est présentée code à gauche, rendu à droite : comparez, c'est le meilleur moyen de comprendre.

01

Une balise, c'est quoi ?

Ouvrante · contenu · fermante

Le HTML est un langage de balisage : il ne calcule pas (ce n'est pas un langage de programmation), il décrit le contenu. Une balise se compose de trois parties :

Code Rendu dans le navigateur 
<h1>Bienvenue</h1>

Bienvenue
🔎 Lecture du code

<h1> = balise ouvrante · Bienvenue = le contenu · </h1> = balise fermante (avec le slash /).

Les balises s'emboîtent comme des poupées russes — jamais en travers :

✅ Imbrication correcte ❌ Imbrication fausse 
<p>Un mot <strong>important</strong> ici</p>
 
<p>Un mot <strong>important</p></strong>
🔎 Pourquoi ?

A gauche, la balise interne ferme avant la balise externe. À droite, elles se croisent : le navigateur ne sait plus qui se termine où.

02

Structurer une page

Squelette · head · body

Toute page respecte le même squelette, en deux zones : le <head> (invisible) et le <body> (visible) :

Code (le squelette) Rendu dans le navigateur 
<!DOCTYPE html>
<html lang="fr">
  <head>
    <meta charset="UTF-8">
    <title>Ma page</title>
  </head>
  <body>
    <!-- le contenu visible ici -->
  </body>
</html>
 
(Onglet du navigateur) : « Ma page »
🔎 Lecture du code

<head> : titre de l'onglet, encodage… rien à l'écran. <body> : tout ce qui s'affiche. Les commentaires <!-- ... --> ne s'affichent jamais.

Dans le <body>, on organise les grandes zones avec de blocs sémantiques — chaque balise dit ce qu'elle contient :

Code (une page organisée) Rendu dans le navigateur 
<body>
  <header>
    <h1>Club réseau du lycée</h1>
  </header>

  <section>
    <h2>Nos activités</h2>
    <article>
      <h3>Atelier câblage</h3>
      <p>Apprendre à sertir un câble.</p>
    </article>
  </section>

  <footer>
    <p>Contact : le club</p>
  </footer>
</body>

Club réseau du lycée


Nos activités

Atelier câblage

Apprendre à sertir un câble.

Contact : le club
🔎 Les blocs sémantiques

header : bandeau · section : grande partie · article : bloc autonome · footer : pied de page. Sans CSS, ces balises se ressemblent presque (juste un espacement) : leur valeur, c'est le sens — pour le navigateur, le référencement… et pour vous quand vous relisez le code.

Mettre du texte en avant : strong, b, em, i

Code Rendu dans le navigateur 
<p>C'est <strong>important</strong>
et <b>en gras</b>.</p>

<p>Un mot <em>accentué</em>
et un terme <i>clin d'œil</i>.</p>

C'est important et en gras.

Un mot accentué et un terme clin d'œil.
🔎 strong/b, em/i : quelle différence ?

strong = important (priorité, urgence) · b = en gras, sans importance particulière · em = emphase (on insiste en lisant) · i = italique (terme étranger, pensée, titre…). À l'écran, strong et b semblent identiques : la différence est le sens — « ceci est capital », pas seulement « ceci est gras ».

Les différents types de balises permettent de structurer le contenu et d'aider au référencement.

🔎 Lecture du code

table le tableau · tr une ligne · th cellule d'en-tête (grasse et centrée) · td cellule de données. Sans CSS, pas de bordures : le tableau existe, mais il est nu.

04

Les propriétés CSS à connaître

Couleur · police · fond · bordure · padding · margin

Le CSS complète le HTML. Une règle cible des éléments et applique des propriétés : sélecteur { propriété: valeur; }. Voici les six propriétés essentielles, appliquées à un même paragraphe :

Code CSS (dans un <style> ou un fichier .css) Rendu 
p.ex1 {
  color: red;
}

Un texte en rouge.
🔎 color

color = la couleur du texte.

Code CSS Rendu 
p.ex2 {
  color: white;
  background-color: darkblue;
}

Un texte blanc sur fond bleu marine.
🔎 background-color

background-color = la couleur du fond derrière le texte.

Code CSS Rendu 
p.ex3 {
  font-family: Georgia, serif;
  font-size: 2em;
  font-weight: bold;
}

Un texte en Georgia, 2em, gras.
🔎 les polices

font-family (on donne plusieurs polices de secours) est une police de caractères·

🔎 la taille des caractères

1 em; est une unité de mesure qui correspond à la taille de la police de caractères utilisée.

🔎 l'épaisseur du trait

font-weight correspond à l'épaisseur du trait que l'on souhaite utiliser.

Code CSS Rendu 
p.ex4 {
  border: 2px solid black;
}

Un texte entouré d'une bordure.
🔎 border

border = bordure : épaisseur + style + couleur (ici : 2 pixels, trait continu, noir).

Code CSS Rendu 
p.ex5 {
  border: 2px dashed orange;
  padding: 15px;
}

Un texte avec 15 pixels de padding : de l'espace intérieur.
🔎 padding

padding = marge intérieur : entre le texte et sa bordure. Ici 15 px d'air tout autour du texte.

Code CSS Rendu 
p.ex6 {
  border: 2px dashed green;
  margin: 30px;
}

Un texte avec 30 pixels de marge : de l'espace extérieur.
🔎 margin — et la comparaison padding/margin

margin = marge extérieur : entre l'élément et ses voisins. Comparez avec l'exemple précédent : même bordure, mais l'élément se détache du reste. À retenir : padding = à l'intérieur (le coussin entre le texte et sa bordure), margin = à l'extérieur (la distance avec les autres).

Code CSS Rendu 
table {
  border-collapse: collapse;
  width: 100%;
}
th, td {
  border: 1px solid #999;
  padding: 6px 10px;
  text-align: left;
}
th {
  background-color: #1a4fb4;
  color: white;
}
Équipement Quantité
Switch 2
Routeur 1
🔎 le style d'un tableau

border-collapse: collapse; colle les bordures des cellules entre elles (sinon, double trait). border sur th, td dessine les cases, padding aère leur contenu, et on réutilise background-color + color pour l'en-tête. C'est avec cela que votre tableau « nu » devient lisible.

05

L'essentiel en une page

Mémo

📌 Mémo 1 — Les balises HTML importantes

Balise Rôle Exemple
<h1> … <h6> Titres, du plus au moins important (un seul h1 par page) <h1>Titre</h1>
<p> Paragraphe <p>Du texte...</p>
<strong> / <b> Important (sens) / gras (forme) <strong>capital</strong>
<em> / <i> Emphase, insister (sens) / italique (forme) <em>accentué</em>
<section> Grande partie de la page « Présentation », « Inventaire »
<article> Bloc autonome dans une section Une fiche, une carte produit
<header> / <footer> Bandeau d'en-tête / pied de page Nom du site / auteur, contact
<table> <tr> <th> <td> Tableau / ligne / cellule d'en-tête / cellule de données Inventaire, planning
<link> Relier une feuille de style CSS <link rel="stylesheet" href="style.css">
<!-- ... --> Commentaire (jamais affiché) <!-- à revoir -->

📌 Mémo 2 — Les propriétés CSS importantes

Propriété Elle règle quoi ? Exemple
color Couleur du texte color: darkblue;
background-color Couleur du fond background-color: #f0f4fb;
font-family Police (plusieurs de secours, séparées par des virgules) font-family: Verdana, sans-serif;
font-size Taille du texte (en pixels) font-size: 20px;
border Bordure : épaisseur + style + couleur border: 2px solid black;
padding Marge intérieure (texte ↔ bordure) padding: 15px;
margin Marge extérieure (élément ↔ voisins) margin: 30px;
🧠 Le piège à ne pas oublier

padding agit à l'intérieur de la bordure, margin à l'extérieur. Et côté HTML : strong/em portent un sens, b/i seulement une forme.
