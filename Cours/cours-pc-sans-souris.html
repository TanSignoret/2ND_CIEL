Utiliser un PC sans souris

Seconde Bac Pro CIEL Durée : 30 min Poste Windows + navigateur

🔹 Pourquoi utiliser les raccourcis clavier ?

Dans un environnement professionnel, maîtriser les raccourcis clavier permet de :

  • Gagner du temps : Effectuer des actions plus rapidement qu'avec une souris.
  • Travailler sans souris : Indispensable pour les serveurs ou en cas de panne matérielle.
  • Améliorer son efficacité : Réduire les mouvements inutiles et automatiser les tâches répétitives.
  • Respecter les normes d'accessibilité : Faciliter l'utilisation pour les personnes en situation de handicap.

Ce cours vous présentera les raccourcis clavier essentiels pour Windows, classés par catégorie.

01

Cours — Raccourcis généraux

À retenir

Ces raccourcis sont universels et fonctionnent dans la plupart des applications Windows.

Action Raccourci Description
Copier Ctrl + C Copie le texte ou le fichier sélectionné dans le presse-papiers.
Coller Ctrl + V Colle le contenu du presse-papiers.
Couper Ctrl + X Coupe le texte ou le fichier sélectionné.
Sélectionner tout Ctrl + A Sélectionne tout le contenu de la fenêtre active.
Annuler Ctrl + Z Annule la dernière action.
Rétablir Ctrl + Y Rétablit la dernière action annulée.
Enregistrer Ctrl + S Enregistre le fichier actuel.
Enregistrer sous Ctrl + Maj + S Ouvre la fenêtre "Enregistrer sous".
Imprimer Ctrl + P Ouvre la fenêtre d'impression.
Rechercher Ctrl + F Ouvre la barre de recherche dans la plupart des applications.

03

Cours — Bureaux virtuels

À retenir
Qu'est-ce qu'un bureau virtuel ?

Les bureaux virtuels permettent d'organiser vos fenêtres en plusieurs espaces de travail. Cela est utile pour :

  • Séparer les tâches (ex: un bureau pour le travail, un autre pour les loisirs).
  • Éviter l'encombrement de la barre des tâches.
  • Travailler plus efficacement en basculant entre les bureaux.
Action Raccourci Description
Ouvrir la vue des bureaux virtuels Win + Tab Ouvre la vue des bureaux virtuels pour les gérer.
Créer un nouveau bureau virtuel Win + Tab → + Ajoute un nouveau bureau virtuel.
Changer de bureau virtuel Win + Ctrl + ← ou → Passe d'un bureau virtuel à un autre.
Déplacer une fenêtre vers un autre bureau Win + Maj + ← ou → Déplace la fenêtre active vers un autre bureau.
Fermer un bureau virtuel Win + Tab → × sur le bureau Ferme le bureau virtuel actuel.

Cours — Capture d'écran

À retenir

Ces raccourcis permettent de capturer tout ou partie de votre écran.

Action Raccourci Description
Capture de l'écran entier Impr. écran Copie tout l'écran dans le presse-papiers.
Capture de la fenêtre active Alt + Impr. écran Copie la fenêtre active dans le presse-papiers.

Cours — Exemples concret

À retenir

Exemple 1 : Copier et coller un texte

Scénario : Vous souhaitez copier un texte depuis un site web et le coller dans un document Word.

  1. Sélectionnez le texte avec la souris ou Maj + Flèches.
  2. Copiez le texte : Ctrl + C.
  3. Ouvrez Word : Win → tapez Word → Entrée.
  4. Collez le texte : Ctrl + V.

Exemple 2 : Naviguer entre plusieurs applications

Scénario : Vous avez ouvert Bloc-notes, la Calculatrice et l'Explorateur de fichiers, et vous souhaitez basculer entre ces applications.

  1. Utilisez Alt + Tab pour basculer entre les applications.
  2. Maintenez Alt enfoncé et utilisez Tab pour naviguer.
  3. Relâchez les touches pour sélectionner l'application souhaitée.

Exemple 3 : Créer une arborescence de dossiers

Scénario : Vous devez créer une arborescence de dossiers pour organiser vos fichiers.

  1. Ouvrez l'Explorateur de fichiers : Win + E.
  2. Naviguez jusqu'au dossier parent (ex: Documents).
  3. Créez un nouveau dossier : Ctrl + Maj + N.
  4. Nommez le dossier et validez avec Entrée.
  5. Ouvrez le dossier et répétez l'opération pour les sous-dossiers.

Cours — Bonnes pratiques

À retenir
Pourquoi adopter les raccourcis clavier ?

Voici quelques bonnes pratiques pour tirer le meilleur parti des raccourcis clavier :

  • Apprenez par cœur les raccourcis les plus utilisés : Commencez par les raccourcis de base comme Ctrl + C, Ctrl + V, Ctrl + S, etc.
  • Utilisez les raccourcis dans tous les contextes : Que ce soit pour naviguer sur le web, travailler dans un traitement de texte ou gérer des fichiers, les raccourcis sont universels.
  • Personnalisez vos raccourcis : Certaines applications (ex: Photoshop, Blender) permettent de personnaliser les raccourcis. Adaptez-les à vos besoins.
  • Entraînez-vous régulièrement : Plus vous utiliserez les raccourcis, plus ils deviendront naturels.
