🐧 Les 10 commandes à connaître

Le minimum vital pour survivre dans un terminal : les commandes vues en TP, avec un exemple prêt à copier pour chacune.

Seconde Bac Pro CIEL TP Systèmes d'exploitation À garder sous la main
⌨️ Avant de commencer

Ouvre un terminal avec Ctrl+Alt+T. Tape la commande, puis appuie sur Entrée.
💡 Astuce : la touche Tab complète automatiquement les noms, et ↑ rappelle les dernières commandes.

01

pwd — Où suis-je ?

Se situer

Affiche le dossier courant (print working directory).

💻 Exemple

pwd → /home/eleve

02

ls — Que contient ce dossier ?

Lister

Liste le contenu du dossier courant.

💻 Exemple

ls → liste simple  ·  ls -l → liste détaillée (taille, date)

03

cd — Se déplacer

Naviguer

Change Directory : aller dans un autre dossier.

Commande Effet
cd Documents Entrer dans le dossier Documents
cd .. Revenir au dossier parent
cd ~ Retour au dossier personnel
04

mkdir — Créer un dossier

Créer

Make Directory.

💻 Exemple

mkdir TP3

05

touch — Créer un fichier vide

Créer
💻 Exemple

touch notes.txt

06

nano — Éditer un fichier texte

Écrire

Petit éditeur simple, directement dans le terminal.

💻 Exemple

nano notes.txt

⌨️ Pour quitter

Ctrl+X puis O (Oui) pour enregistrer, Entrée pour confirmer le nom du fichier.

07

cat — Afficher un fichier

Lire

Affiche tout le contenu d'un fichier à l'écran.

💻 Exemple

cat notes.txt

08

cp — Copier un fichier

Copier
💻 Exemple

cp notes.txt sauvegarde.txt

Variante : mv pour déplacer ou renommer un fichier.

09

rm — Supprimer ⚠️

Supprimer

Remove. ⚠️ Pas de corbeille : la suppression est définitive !

💻 Exemple

rm sauvegarde.txt (fichier)  ·  rm -r TP3 (dossier et son contenu)

⚠️ Règle de sécurité

Ne jamais supprimer en dehors de son dossier personnel.

10

df -h — Espace disque

Diagnostic

Affiche l'espace libre et utilisé sur les disques (tailles lisibles en Go/Mo grâce à l'option -h).

💻 Exemple

df -h

✅ À retenir

Le terminal fait tout ce que la souris fait, mais au clavier — et parfois bien plus vite. rm supprime définitivement : réfléchir avant d'appuyer sur Entrée. Et les noms des commandes sont logiques : c'est de l'anglais abrégé (print working directory, list, make directory, remove...).
